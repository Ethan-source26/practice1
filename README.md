# 电控第一次作业说明文档
## 2.定时器
- 计算过程
  
  $\frac{(PSC+1)\times(ARR+1)}{定时器时钟}=0.001s$

  定时器时钟来自APB1，HSE(8MHz)经过锁相环 *9变为72MHz，APB1分频为2，再 *2（APB1分频不为1时乘2）后变为72MHz作为定时器时钟

  $(71+1)\times(999+1)=0.001\times72000000$

  所以PSC = 71，ARR = 999
